## 三、关键防御机制实测细节

**页面守卫**（require_page_admin）：未登录/非 admin 访问后台页 → `HTTPException(302, Location=/login)` → 异常处理器转换为标准 302 跳转。实测 urllib 跟随重定向后最终 URL 落在 `/login`。

**RBAC 双层设计**：
- 接口级：`Depends(require_admin)` 校验 JWT payload.role，非 admin 返回 40301；
- 页面级：require_page_admin 校验 cookie token，非 admin 302 到登录页。
operator 角色实测：越权写接口 403、越权页面 302，双层全部拦截。

## 四、测试发现并修复的缺陷（P-17）

**现象**：admin 登录后调用 `GET /api/audit/conversations/export` 返回 404。

**根因**：FastAPI 按定义顺序匹配路由，`GET /api/audit/conversations/{session_id}`（通配路由）定义在 `export`（字面量路由）之前，"export" 被 `{session_id}` 捕获，按不存在的会话查询导致 404。

**修复**：将 export 路由注册提前至通配路由之前（`src/admin_app.py`），并加注释说明顺序约束。修复后复测 HTTP 200，CSV 正常导出（含 BOM 头，Excel 兼容）。
