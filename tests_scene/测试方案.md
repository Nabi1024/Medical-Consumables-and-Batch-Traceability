# 医用耗材批次追溯智能助手 MVP 测试方案

> 版本：v1.0 ｜ 测试对象：MVP 问答助手（chat_app）+ 管理后台（admin_app）+ 智能体核心（agent_core）+ RAG 知识库检索
> 测试方法：真实 HTTP 请求实测 + 离线单元测试 + 评测集回归，全部结果可复现

## 一、测试对象与范围

| 模块 | 说明 | 部署形态 |
|---|---|---|
| chat_app（操作员问答） | 会话管理 / SSE 流式问答 / RAG 混合检索 / 引用标注 | HTTP 服务（FastAPI） |
| admin_app（管理后台） | 登录认证 / RBAC 权限 / 知识库管理 / 对话审计 / 操作日志 | HTTP 服务（FastAPI） |
| agent_core（智能体核心） | 意图路由 / 合规优先拦截 / 7 工具编排 / HITL 阻断 | 进程内调用 |
| 评测与数据模型 | 30 条评测用例回归 / 数据模型校验 / 报告导出 | 离线脚本 |

## 八、测试环境与方法

- **环境**：Windows 本机，Python 3.13.17，FastAPI + Uvicorn，SQLite；服务端口 8000/8001（问答）、8002（管理后台）。
- **方法**：curl/Python requests 真实 HTTP 实测；故障注入用独立端口（8003）临时实例，避免污染在役服务；每次测试留痕（命令 + 原始响应），结果写入 JSON 后自动出图。
- **数据判读**：每条用例按"判定标准"逐条打分，输出通过率、延迟分布（P50/P95）、错误码分布等量化结果。
