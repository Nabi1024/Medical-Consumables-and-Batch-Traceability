# 评测报告

> 基于 `qa_evaluation_cases.json`（30 条用例）的离线评测结果

## 1. 评测方法

`eval_agent.py` 加载 30 条用例，逐条通过本地 `agent_core` 的 `RuleBasedPlanner`
（离线 Mock 模式）执行，并按可检查项打分：

- **rag_query（10 条）**：期望命中 RAG 检索，重点验证 3 条「知识库无相关内容」陷阱
  必须返回「现有制度文档中无该项内容」；
- **agent_tool_call（10 条）**：检查实际调用的工具序列是否覆盖期望工具（子集匹配，
  含正确依赖顺序：检索→档案→库存效期→草稿）；
- **risk_intent（5 条）**：违规意图（绕过审批、篡改追溯、隐瞒效期、跳过校验等）
  必须**拒绝执行**，即不调用任何工具且回答含拒答关键词；
- **multi_turn_context（5 条）**：验证跨轮次实体指代与草稿确认衔接。

## 2. 评分结果

| 类别                | 通过 / 总数 |
| ------------------- | ----------- |
| rag_query           | 10 / 10     |
| agent_tool_call     | 10 / 10     |
| risk_intent         | 5 / 5       |
| multi_turn_context  | 5 / 5       |
| **合计**            | **30 / 30** |

总分：**100%**（基线版本为 14/30 ≈ 46.7%，经重写合规优先意图路由后达成全通过）。

## 3. 关键修复（相对基线）

- 重写 `RuleBasedPlanner` 为「合规优先」意图路由：违规 > 确认 > 追溯 > 工单 >
  申领 > 入库问询 > 档案库存 > RAG，覆盖全部工具流与依赖顺序；
- 新增违规意图**拒答**分支（risk_intent 0/5 → 5/5）；
- 新增 HITL **批次缺失阻断** 与越界主题（招标 / 账期 / 排班等）**无内容检测**
  （no-content 陷阱 0/3 → 3/3）；
- 修复 `agent_core._synthesize` 在 `data=None` 时 `.get` 崩溃，使拒答 / 阻断 /
  无内容话术可正确返回。

## 4. 复现方式

```bash
python cli.py eval      # 或 python eval_agent.py
```

输出逐条 PASS/FAIL 与按类别汇总，结尾打印总分。
